# 琴行管理系统 AI Native 产品需求设计（MVP v1.1 评审稿）

> 本文继承《系统需求设计 AI Native（MVP v1.0）》全部未列明内容，仅记录新原型带来的产品形态调整。  
> 业务规则继续以《系统需求设计 V2（MVP v1.1 评审稿）》及其通过后的版本为准。

## 1. 产品定位调整

系统采用“AI + 结构化业务工作区”的协同形态：

- AI 负责理解意图、最少补参、解释和生成 Preview；
- 结构化工作区负责实时浏览、核对、表单输入、Preview、确认、回执和 AI 不可用时的关键办理；
- AI 是主要发起入口，但不是唯一入口；
- 两条入口必须共用 Core 领域服务、Preview/Confirm、幂等和审计，不能形成第二套业务规则。

## 2. 桌面端信息架构

桌面端改为“全局侧栏 + 页面内双栏”：

| 区域 | 职责 |
|---|---|
| 全局侧栏 | 一级业务导航、当前身份和账号入口；最近任务可放入二级入口或任务抽屉。 |
| 对话区 | 当前任务消息、补问、进度、Preview 摘要和 Receipt 摘要。 |
| 结构化工作区 | 实时业务事实、列表、日历、表单、Preview、确认和回执。 |

宽屏并列显示对话区与工作区；平板和手机切换显示，不得省略金额、对象、渠道、状态变化或确认按钮。

## 3. 四个一级页面

### 3.1 工作台

默认加载 Core 的确定性经营概览，不等待模型欢迎语。至少包含今日课程、已结束待确认、欠费、冻结、待处理工资、关账提醒、最近业务记录和最近任务入口。

### 3.2 学生与账户

支持学生搜索、状态筛选、基本资料、课程账户、账户流水和账户相关办理。店主可使用交费、赠送、改价、最终退款及可用冲正入口；老师只能看到经过权限裁剪的教学信息。

### 3.3 排课与课消

支持完整周视图、单节排课、按周批量排课、调课、取消、确认上课、店主撤销确认和冲突展示。批量排课任一节冲突时不得部分创建。

### 3.4 收支与报表

支持经营/现金双口径、收支流水、工资、关账检查、关账和最近一次重开账。关账阻断等级以 Core 返回为准。

## 4. 会话与导航

- 会话归属于业务任务，不归属于页面；
- 切换页面不自动创建新线程，也不清空当前任务；
- 页面上下文必须显式传递；金额、渠道、手续费、月份、退款对象和支付日期不得因切页自动继承；
- 结构化按钮可创建新任务，也可继续当前匹配任务，但必须明确提示；
- 刷新、深链、重新登录和最近任务恢复后，重新从 Core 读取事实和 Preview 状态；已执行任务只展示最终 Receipt；
- 最近任务能力保留，可通过任务抽屉或二级入口提供，不要求占用一级导航。

## 5. 结构化入口与 AI 降级

结构化页面的关键按钮必须在模型不可用时仍能完成：填写 → Core Preview → 浏览器确认 → 查询 Receipt。AI 可以预填或解释，但不负责提交确认。

至少覆盖：排课、批量排课、调课、取消、确认上课、撤销确认、交费、赠送、改价、最终退款、冲正、工资生成/支付/取消支付、手工收支、关账和重开账。

## 6. 动态工作区组件

在原 §9 组件白名单中增加：

- `student-detail`；
- `course-account-detail`；
- `weekly-schedule`；
- `finance-comparison`；
- `payroll-detail`；
- `preclose-checklist`；
- `task-history`。

组件只展示结构化数据、来源和允许动作，不执行前端金额计算，不接收 HTML、脚本或模型生成代码。

## 7. 角色化体验

- 店主可见四个一级页面及全部允许的办理入口；
- 老师默认只见工作台、自己的排课和必要教学信息；
- 老师不得通过导航、自然语言、历史任务、深链或导出看到余额、交费、赠送、退款、冲正、全店现金、全店经营报表或其他老师工资；
- 页面隐藏不是授权，服务端必须重新校验角色、教师归属和资源访问权。

## 8. 新增验收场景

1. 工作台概览和明细使用同一查询口径，指标数量、金额和状态一致；
2. 切换四个页面后当前任务仍可继续，刷新后任务、Preview 和 Receipt 可恢复；
3. AI 不可用时，四个页面的关键查询和 L1/L2 操作仍可完成；
4. 结构化入口和 AI 入口对同一业务命令生成相同 Preview/Receipt；
5. 老师打开店主深链时不加载敏感数据；
6. 同名学生和多课程必须先选择，选择前不展示账户金额；
7. 关账检查展示阻断项、提醒项、来源记录和重新检查结果；
8. 未知工作区或 Preview schemaVersion 只读降级，不出现通用确认按钮。
