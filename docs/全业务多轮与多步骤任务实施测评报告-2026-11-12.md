本轮新增和复测的功能包括：

- 多步骤计划写入 Agent 任务状态，并带版本号；
- 未确认前更正姓名、金额、渠道、课程和单价时，更新原计划，不新建第二笔业务；
- 已完成步骤不能被后续更正改写；
- 不支持或冲突的问题会保留在计划中，标为阻塞，阻塞未解决前不生成预览；
- 任务保存时模型调用在数据库事务外，保存前重新核对版本，旧版本不能覆盖新版本；
- 办理计划可在 Workspace 和 Web 中显示步骤、状态和问题；
- 已应用 Agent 任务版本迁移 `007_dialogue_task_revision.sql`，真实本机 PostgreSQL 定向测试通过。
