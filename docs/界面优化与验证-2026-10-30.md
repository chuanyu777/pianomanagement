# 界面优化与验证（2026-10-30）

本轮基于 `refactor/ai-dialogue-pipeline` 实现浏览器批注中的界面调整。

## 改动

- 首页经营指标增加业务入口，今日课程可定位排课详情，近期流水可按学生姓名进入账户页。利润与现金净额保留 Core 返回的金额字符串，仅按正负值控制显示颜色；零值使用中性色。
- 移除首页与业务页的重复说明，压缩标题区域。统一学生、财务、教师与课程页签；新建与提交使用主按钮，账户内并列操作使用普通按钮，退款等危险操作保留红色。
- 空输入和运行期间的发送按钮使用可辨识的灰色状态；Enter 发送、Shift+Enter 换行，组合输入期间的 Enter 不发送。
- 学生目录缩窄、降低行高，仅显示姓名和学籍。开户入口放在当前学生旁，单账户直接显示详情，多账户才显示切换器。
- 教师与课程使用可搜索目录和详情卡，保留现有 Preview、确认与账号开通流程。详情的“询问助手”将当前教师或课程的本周排课问题填入输入框，由用户发送。
- 课表使用上海时间 07:00—22:00 时间轴，按真实时长定位；重叠课程分列且显示教师。时间窗外的课程另列，短课可查看完整详情；窄工作区可横向和纵向滚动。
- 后续密度调整：每半小时从 36px 降为 24px，时间轴总高度从 1080px 降为 720px；网格线、时间标签及课程位置共用同一缩放比例。
- Core 排课列表增加白名单教师 `id/name`，写接口响应不变。OpenAPI 与 Client 使用项目命令重新生成。

## 验证与边界

- 完整门禁：`npm run check` 通过，包括 typecheck、lint、test、build；853 项测试通过，35 项因数据库等环境条件跳过。构建保留现有的大包体积提示。
- Core 定向测试 25/25，包含真实 PostgreSQL 的教师姓名、字段白名单和双教师归属隔离断言；临时测试库已清理。
- 新增时间轴、教师课程目录和键盘交互检查均进行过失败再通过验证；键盘检查还通过移除处理器的变异验证。
- Docker HTTP smoke 已读取当前周的两节真实课程，教师字段均严格为 `id/name`。
- 内置浏览器已用真实本地数据走查 1126×757 桌面与 390×844 窄屏布局，检查学生账户、教师详情、统一页签与发送状态；不据此声称全设备验收完成。
- 最终浏览器走查已验证利润卡跳到财务页且负值保持红色，时间轴课程可打开完整时间、教师、学生及课程详情。“询问助手”预填当前教师本周排课问题，Enter 提交后真实模型返回该教师本周无排课的结果。
- 不代表所有自然语言、跨会话恢复、资金流程或全设备 E2E 已完成。薪酬详情仍通过结构化详情卡查看；现有 AI 基础资料查询不会返回完整薪酬信息，本轮不扩展该能力。
- 首页冻结学生及欠费入口当前进入学生工作区，近期流水按姓名搜索，不宣称完整筛选深链已经实现。
- 本机镜像仓库访问超时，因此本地 Docker 更新使用已有镜像作为基础，覆盖本轮已构建的 Core/Web 产物；本轮未变更依赖或数据库模型。

## 日期、按钮及操作入口后续调整

- 统一替换九处原生日期、日期时间与月份控件，使用中文日历、快捷日期与可编辑输入。日期时间保留分钟精度，父表单继续按上海时间提交；直接输入后点击提交的时序有回归测试。
- 手工收支入口移到流水页顶部；账户交费、赠送、改价、退款、工资生成/支付/撤销与重新开账统一为带标签的弹窗，生成确认单后仍须浏览器直连 Core 确认执行。失败时保留输入。
- 全局按钮禁用状态统一为可读灰底，避免局部主按钮背景覆盖禁用样式。现金汇总改成并列的收入、支出、净额三个区域。
- 业务页助手默认加宽，支持拖动或键盘调整宽度；快捷问题换行，窄屏保持纵向布局。
- 本轮完整门禁 893 项通过、35 项按环境条件跳过；仅新增 Web 直接声明已有 dayjs 1.11.23，未升级其他依赖。上文的“未变更依赖”仅适用于此前镜像更新。
- 用户要求经营工作区的整体内容取舍、新布局先评审。独立可点击原型使用示意数据，不接入真实业务；该整体重排尚未应用到项目代码。
